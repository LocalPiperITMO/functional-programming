## Описание лабораторной работы

Цель: получить навыки работы с вводом/выводом, потоковой обработкой данных, командной строкой.
В рамках лабораторной работы вам предлагается повторно реализовать лабораторную работу по предмету "Вычислительная математика" посвящённую интерполяции (в разные годы это лабораторная работа 3 или 4) со следующими дополнениями:

- обязательно должна быть реализована линейная интерполяция;
- настройки алгоритма интерполяции и выводимых данных должны задаваться через аргументы командной строки:
  - какие алгоритмы использовать (в том числе два сразу);
  - частота дискретизации результирующих данных;
  - и т.п.;
- входные данные должны задаваться в текстовом формате на подобии ".csv" (к примеру `x;y\n` или `x\ty\n`) и подаваться на стандартный ввод, входные данные должны быть отсортированы по возрастанию x;
- выходные данные должны подаваться на стандартный вывод;
- программа должна работать в потоковом режиме (пример -- cat | grep 11), это значит, что при запуске программы она должна ожидать получения данных на стандартный ввод, и, по мере получения достаточного количества данных, должна выводить рассчитанные точки в стандартный вывод;

Язык - Clojure.

## Интерполяция
### Линейная интерполяция
Линейная интерполяция — это метод интерполяции, который использует линейные сегменты для аппроксимации значений функции между заданными точками. Если у нас есть две точки $(x_1,y_1)$ и $(x_2,y_2)$, то значение $y$ в произвольной точке $x$ можно вычислить с помощью формулы:

$y = y_1 + (y_2 - y_1) \cdot \frac{(x - x_1)}{(x_2 - x_1)}$

**Код метода**
```clojure
(defn linear-interpolation [points step]
  (let [[p1 p2] points
        [x1 y1] p1
        [x2 y2] p2
        x-values (range x1 (+ step x2) step)]
    (map (fn [x]
           (let [t (/ (- x x1) (- x2 x1))]
             [(double x) (+ y1 (* t (- y2 y1)))]))
         x-values)))
```

**Преимущества метода**
- Простота реализации
- Высокая скорость работы

**Недостатки метода**
- Низкая точность для функций с резкими изменениями кривизны
- Невозможно учесть глобальное поведение функции

### Интерполяция Лагранжа
Интерполяция Лагранжа — это метод полиномиальной интерполяции, использующий полином, который проходит через все заданные точки. Для $n$ точек этот полином задаётся следующим образом:

$L(x) = \sum_{i=0}^{n - 1} {y_i \prod_{j=0, j \neq i}^{n - 1}{\frac{x - x_i}{x_i - x_j}}}$

Где $L(x)$— интерполяционный полином, а $x_i,y_i$​ — известные точки.

Этот метод может дать точное решение для заданных точек, однако его вычислительная сложность возрастает с увеличением количества точек

**Код метода**
```clojure
(defn lagrange-polynomial [points x]
  (let [n (count points)]
    (reduce
     (fn [acc i]
       (let [[xi yi] (nth points i)
             li (reduce (fn [li j]
                          (if (not= i j)
                            (let [[xj _] (nth points j)]
                              (* li (/ (- x xj) (- xi xj))))
                            li))
                        1
                        (range n))]
         (+ acc (* li yi))))
     0
     (range n))))

(defn lagrange-interpolation [points step start-x end-x]
  (let [x-values (range start-x (+ end-x step) step)]
    (map (fn [x] [x (lagrange-polynomial points x)]) x-values)))
```
**Преимущества метода**
- Даёт точные результаты для заданных точек
- Может аппроксимировать сложные функции

**Недостатки метода**
- Высокая вычислительная сложность
- Может вызывать эффект Рунге (осцилляции) при большом количестве точек
